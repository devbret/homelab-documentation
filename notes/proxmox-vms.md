I presently have 7 virtual machines available in my Proxmox VE. I use these virtual machines to explore unique Linux distributions without having to install any of them direclty on hardware.

## Experimenting With Different Linux Distros

The Linux operating systems I maintain as virtual machines were each selected for specific reasons. Which includes the following:

### Kali Linux

[Kali Linux](https://www.kali.org/) is a Debian-based distribution intended for cybersecurity and digital forensics. It comes with hundreds of tools preinstalled. It is maintained by [Offensive Security](https://www.offsec.com/) (OffSec) with regular updates since March of 2013.

### Ubuntu

[Ubuntu](https://ubuntu.com/) is a Debian-based distro which has been maintained by [Canonical](https://canonical.com/) since 2004. This operating system is widely considered to be a default Linux distribution.

### CachyOS

[CachyOS](https://cachyos.org/) is a popular Arch-based Linux distribution known for customization, optimization and gaming. This Linux distro is maintained by an independent team of contributors from around the planet.

### Mageia

Since 2010, [Mageia](https://www.mageia.org/en/) has been a community run Linux distribution carrying on the tradition of Mandrake and Mandriva Linux. The nonprofit responsible for Mageia is based in France.

### Debian

Founded in 1993 by Ian Murdock, [Debian](https://www.debian.org/) is one of the oldest Linux distros in continuous operation. It bills itself as "the universal operating system" and is known for stability.

### Zorin OS

[Zorin OS](https://zorin.com/os) was started (and is still based) in Dublin, Ireland on July 1st of 2009. It is built on top of Ubuntu and aims to make switching from Windows or macOS easier.

### VanillaOS

[Vanilla OS](https://vanillaos.org/) is an immutable, atomic Linux distro built around the GNOME desktop. This OS was founded by Mirko Brombin, who also created [Bottles](https://usebottles.com/), with a stable release arriving at the end of 2022.
